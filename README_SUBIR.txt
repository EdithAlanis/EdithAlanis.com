INSTRUCCIONES PARA SUBIR A GITHUB PAGES

1. Abre tu repositorio de GitHub Pages.
2. Entra al archivo index.html y reemplázalo con este index.html.
3. Sube también styles.css y script.js en la misma carpeta principal.
4. Guarda los cambios con Commit changes.
5. Espera 1 a 3 minutos y abre edithalanis.com.

NOTAS
- Esta versión no usa fotografías personales.
- La Red Nacional ya funciona por Estado > Municipio > Tarjetas de coinventores.
- Las áreas tecnológicas tienen tarjetas visuales institucionales sin expedientes.
- Para añadir más coinventores, editar el bloque const data en script.js.


CONTADOR DE VISITANTES Y UBICACIÓN
1. El sitio ya incluye la sección "Visitantes del Portal".
2. Para mostrar visitas reales y ubicación pública, crea un contador gratuito en ClustrMaps o Flag Counter.
3. Copia el código HTML que te entregue el servicio.
4. Abre index.html y reemplaza este bloque:
   <div class="visitor-map-placeholder" id="visitorMap"> ... </div>
   por el código del contador/mapa.
5. Guarda, sube los archivos a GitHub y espera unos minutos.

Recomendación para lanzamiento en Facebook: usar ClustrMaps si quieres mapa mundial, o Flag Counter si quieres banderas por país.
