## Instrucciones para subir a GitHub

1. Abre el repositorio de `edithalanis.com`.
2. Sube o reemplaza `index.html` en la raíz del repositorio.
3. Sube la carpeta `assets` completa.
4. Guarda los cambios con un commit.
5. Espera a que GitHub Pages publique la actualización.
